# ONDE — iOS app project

A Capacitor wrapper around the complete ONDE web app in `www/`. Interface language: French. Includes the NAM badge, YouTube/SoundCloud exploration, local collections, full player, similar-track queue, loop control, safe-area-aware responsive layout, icons and web manifest.

## Build the iOS app

**Requires macOS and Xcode** for a local native build (Xcode 15+ recommended).

```sh
npm install
npm run web:check
npm run ios:setup      # creates ios/ with Capacitor if absent, then syncs www/
npx cap open ios
```

In Xcode, choose the `App` scheme and an iOS device/simulator. For an installable device IPA, set a unique Apple Developer Team and signing/provisioning in Signing & Capabilities, then Archive → Distribute App. Device sideloading requires a signed IPA and a provisioning profile that covers the target device (or another valid distribution method).

## GitHub Actions build (no Mac owned by you)

GitHub Actions uses a hosted macOS runner; it still builds on a Mac remotely. Push the project to GitHub and run **Actions → Build ONDE iOS → Run workflow**. The workflow produces `ONDE-unsigned.xcarchive.zip` for subsequent signing. This unsigned archive is not directly installable or sideloadable.

To have the workflow also export `ONDE.ipa`, configure repository Actions secrets:

- `IOS_CERTIFICATE_BASE64`: base64-encoded Apple distribution/development `.p12` certificate.
- `IOS_CERTIFICATE_PASSWORD`: password for that `.p12`.
- `IOS_PROVISIONING_PROFILE_BASE64`: base64-encoded Ad Hoc profile for `com.onde.nam.app`, with registered device UDIDs.
- `IOS_TEAM_ID`: Apple Developer Team ID. Supply a matching Apple Distribution `.p12` and an Ad Hoc provisioning profile named as read from the profile itself; its bundle identifier must be `com.onde.nam.app`, and registered device UDIDs are needed for Ad Hoc installs.

The profile's provisioning-profile display name must match `ONDE Ad Hoc` as currently specified in ExportOptions.plist; adjust the plist mapping if yours differs. A free Apple ID / unsigned output does **not** yield a universally installable IPA. Do not commit signing credentials.

## App behavior and caveats

- YouTube playback/search uses third-party public endpoints and the official privacy-enhanced embedded player. Network reachability, video availability, autoplay policies, region/age restrictions and YouTube ads remain controlled by YouTube.
- SoundCloud and supplied HTTPS audio URLs use their own embedded player/source. Their availability, playback controls and advertising are controlled by the provider. **ONDE does not block, hide, or remove ads**; the app cannot promise an ad-free experience.
- Collections are stored in browser local storage on the device and are not synced to a server. Audio playback/background behavior on iOS is subject to platform and provider policies.
- Do not use third-party content without required rights. No API keys or credentials are included.
